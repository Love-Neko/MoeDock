# 萌坞 (MoeDock)

![图标预览](./图标预览.gif)

一套面向桌面 Dock 的二次元风格图标资源与预览工具。项目提供透明底 PNG、包含多尺寸的 ICO，以及一个可直接打开的交互式网页预览页，适合制作个性化桌面、应用启动器和主题素材。

## 内容

- `例图/PNG图标/`：高清透明 PNG 图标
- `例图/ICO图标/`：16–256 像素多尺寸 ICO 图标
- `dock_preview.html`：图库与 Dock 悬停缩放效果预览
- `scripts/`：去背景、PNG 转 ICO、预览页更新等脚本
- `tests/`：基础流程测试

## 使用

直接双击 `dock_preview.html`，即可查看图标墙并体验 Dock 图标的悬停放大效果。

脚本依赖见 [`requirements.txt`](./requirements.txt)。
